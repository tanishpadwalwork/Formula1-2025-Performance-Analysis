# Formula1-2025-Performance-Analysis
Interactive Formula 1 2025 Performance Dashboard built in Microsoft Excel using Pivot Tables, Pivot Charts, Slicers, KPIs, and data visualization techniques to analyze driver and constructor performance.

## 📌 Overview

This project is an interactive dashboard built in **Microsoft Excel** using the **Formula 1 2025 Season** dataset. The dashboard provides insights into driver and constructor performance through dynamic KPIs, Pivot Tables, Pivot Charts, and Slicers.

The objective of this project was to strengthen my Excel skills by working with a real-world dataset and creating an interactive dashboard for data analysis.

---

## 📊 Dashboard Features

- Dynamic KPI Cards
- Interactive Slicers
- Pivot Tables
- Pivot Charts
- Driver Championship Standings
- Constructor Championship Standings
- Race Wins Analysis
- Podium Finish Analysis
- Pole Position Conversion Rate
- 2024 vs 2025 Season Comparison

---

## 📈 KPIs Included

- Championship Leader
- Championship Points
- Total Drivers
- Total Teams
- Total Races
- Pole Position Conversion %

## 📂 Dataset

The dashboard is built using publicly available Formula 1 race results and qualifying data for the **2025 season**, with selected comparisons to the **2024 season**.

---

## 🎯 Business Questions Answered

- Who scored the most championship points?
- Which driver won the most races?
- Which driver achieved the most podium finishes?
- Which constructor scored the most points?
- Which constructor was the most consistent?
- Does starting from Pole Position increase the chances of winning?
- How did the 2025 season compare with the 2024 season?
